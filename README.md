# Курсовой проект «Сетевой чат»

Консольное клиент-серверное приложение на языке Java для обмена текстовыми сообщениями по сети.
Проект выполнен в рамках курса по профессиональной переподготовке.

## Описание проекта

Приложение состоит из двух частей:
1. **Сервер (`Server`)** - ожидает подключения клиентов, принимает сообщения и рассылает их всем остальным участникам чата.
2. **Клиент (`Client`)** - подключается к серверу, позволяет ввести имя и обмениваться сообщениями с другими участниками.

Сервер может одновременно обслуживать нескольких клиентов (используется многопоточность). Все сообщения записываются в файлы логов.

## Архитектура и протокол обмена

### Сколько потоков и за что отвечают

#### На сервере:
1. Главный поток (main) - создаёт ServerSocket и в бесконечном цикле ждёт новых клиентов (accept()). Как только клиент подключился, главный поток не начинает с ним общаться, а передаёт его отдельному потоку.
2. Поток на каждого клиента - для каждого подключения создаётся свой ClientHandler (наследник Thread или Runnable). Этот поток читает сообщения от клиента, логирует их и рассылает всем остальным. Именно поэтому сервер может обслуживать много клиентов одновременно.

#### На клиенте:
1. Поток для чтения с консоли - ждёт, что пользователь введёт текст, и отправляет его на сервер.
2. Поток для чтения с сервера - постоянно слушает, не пришло ли новое сообщение, и выводит его на экран. Без этого клиент не смог бы одновременно и писать, и получать.

### Протокол обмена сообщениями

Всё будет текстом, каждая строка заканчивается символом перевода строки \n.

1. Подключение и имя. После подключения клиент первой строкой отправляет своё имя (например, Аня). Сервер запоминает его.
2. Обычное сообщение. Клиент отправляет просто текст, например Привет всем!. Сервер рассылает его другим в виде: [Аня]: Привет всем!.
3. Выход. Клиент отправляет строку /exit. Сервер закрывает соединение и сообщает остальным, что пользователь вышел. Клиент после этого завершает работу.

## Используемые технологии

* **Java 17** (или укажи свою версию JDK, например, Java 21)
* **Gradle** (система сборки)
* **JUnit 5** (для unit-тестов)
* **Многопоточность (Threads, Sockets)** для работы с сетью

## Структура проекта

* `src/main/java/ru/netology/chat/Server.java` - точка входа для сервера.
* `src/main/java/ru/netology/chat/ClientHandler.java` - класс, обрабатывающий подключение одного клиента (работает в отдельном потоке).
* `src/main/java/ru/netology/chat/Client.java` - точка входа для клиента.
* `src/main/resources/settings.txt` - файл настроек (содержит порт сервера).
* `file.log` - файл логирования на сервере (создается автоматически).
* `client_file.log` - файл логирования на клиенте (создается автоматически).

## Настройка (settings.txt)

Перед запуском убедитесь, что в файле `src/main/resources/settings.txt` указан нужный порт.
Пример содержимого:
```text
port=8080
```
## Инструкция по запуску

### Запуск через среду разработки (IDE)
1. Запустите класс Server (метод main). В консоли появится сообщение «Сервер запущен на порту 8080».
2. Запустите класс Client. В консоли появится запрос «Введите ваше имя:».
3. Для проверки работы нескольких пользователей запустите второй экземпляр клиента (в IDE это можно сделать, разрешив параллельный запуск в настройках конфигурации).
4. Введите имена и общайтесь.

### Запуск через терминал (Gradle)
* Запуск сервера: ./gradlew run
* Запуск клиента (в отдельном окне терминала): ./gradlew run -PmainClass=ru.netology.chat.Client

### Как пользоваться чатом
* Отправка сообщения: просто введите текст и нажмите Enter.
* Выход из чата: введите команду /exit и нажмите Enter. Клиент корректно отключится от сервера, а сервер уведомит об этом остальных участников.

### Логирование
* Сервер записывает все полученные сообщения, а также время подключения и отключения пользователей в файл file.log. Файл дополняется при каждом запуске и не перезаписывается.
* Клиент записывает все отправленные и полученные сообщения в файл client_file.log.

### Тестирование
В проекте реализованы unit-тесты (JUnit 5) для проверки вспомогательной логики (например, форматирования сообщений).
Для запуска тестов используйте команду:
```text
./gradlew test
```
Или запустите их средствами IDE (зеленая стрелочка рядом с классом теста).
